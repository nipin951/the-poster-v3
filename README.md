# Faroluna — The Poster for a Place That Isn't There

A vintage travel poster for Faroluna, the island the moon visits first: a striped lighthouse under a cratered moon, light beams sweeping a wavy sea, and a ferry that departs nightly from a country that does not exist. Drawn entirely in code with PIL — gradient night sky, seeded stars, moonlight path on the water, hand-set serif typography.

- `build_entry.py` — draws `entry.png` (1024×1024).
- `main.py` — hands the poster in: copies `entry.png` to `/output/entry.png`.
